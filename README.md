# SwiftBot Navigation — Java

A university programming project developed in Java using the SwiftBot robot.

## Project Overview

This project focuses on controlling a SwiftBot robot using QR-code instructions, allowing it to navigate and retrace its movements.

## Features

- QR-code instruction processing
- Robot navigation and movement control
- Route retracing
- Input validation and exception handling
- Logging to support debugging

## Technologies Used

- Java
- Eclipse IDE
- Maven
- SwiftBot hardware and supporting libraries

## What I Learned

Through this project, I developed my understanding of Java programming, object-oriented design, debugging and working with physical hardware.

It also helped me understand the importance of handling unexpected inputs and testing software that controls real-world devices.

## Project Context

Developed as part of my Computer Science studies at Brunel University London.
